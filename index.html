Order of Precedence (Evaluation Priority)

When combining logical operators without parentheses, compound expressions evaluate strictly from highest precedence to lowest.

Precedence Evaluation Pipeline Architecture

Priority Operator Name Symbol Rule / Note
1 Parentheses ( ) Always evaluated first; explicitly overrides standard operator precedence order.
2 Negation (NOT) ¬, ~ Highest operator priority; applies directly to the immediate adjacent target statement.
3 Conjunction (AND) ∧, & Evaluated strictly before OR, XOR, Conditional, or Biconditional operators.
4 Disjunction (OR) & XOR ∨, ⊕ Evaluated after AND, but takes priority over implication / conditional operators.
5 Conditional (IF...THEN) → Evaluated after standard logical connectives.
6 Biconditional (IFF) ↔ Lowest operator precedence; evaluated last in unparenthesized expressions.

Worked Expression Evaluation Trace 

Evaluate expression: (p ∨ q) ∧ ¬p given p = False, q = True

Step 1: Evaluate Parentheses  ⇒ (False ∨ True) = True
Step 2: Evaluate Negation     ⇒ ¬False = True
Step 3: Evaluate Conjunction  ⇒ True ∧ True = True

Final Result = True

Predicates & Quantifier Logic

A predicate P(x) is a statement with variables that becomes a proposition with a truth value when assigned an element from a Domain of Discourse (U).

∀ Universal Quantifier

"For All" / "For Every"

∀x P(x) asserts that predicate P(x) is TRUE for every single element x in domain U. A single counterexample makes it FALSE.

Negation Rule (De Morgan):
¬(∀x P(x)) ≡ ∃x ¬P(x)
∃ Existential Quantifier

"There Exists" / "For At Least One"

∃x P(x) asserts that predicate P(x) is TRUE for at least one element x in domain U. Requires proving just one instance.

Negation Rule (De Morgan):
¬(∃x P(x)) ≡ ∀x ¬P(x)

Set Notation & Subset Relations

A set is an unordered collection of distinct elements. Relationships between sets form the foundational bedrock of mathematical logic and computer science.

Symbol Concept Formal Definition Example
∈ / ∉ Element Membership x ∈ A (x is in A) / x ∉ A (x is not in A) 3 ∈ {1, 2, 3}
⊆ Subset A ⊆ B ≡ ∀x (x ∈ A → x ∈ B) {1, 2} ⊆ {1, 2, 3}
⊂ Proper Subset A ⊂ B ≡ (A ⊆ B) ∧ (A ≠ B) {1, 2} ⊂ {1, 2, 3}
∅ Empty / Null Set The set containing 0 elements: {} ∅ ⊆ A for every set A
𝒫(A) Power Set Set of all subsets of A; |𝒫(A)| = 2|A| 𝒫({1,2}) = {∅, {1}, {2}, {1,2}}

Fundamental Set Operations & Venn Diagrams

Union: A ∪ B

{x | x ∈ A ∨ x ∈ B}

Elements in A, or B, or both.
Intersection: A ∩ B

{x | x ∈ A ∧ x ∈ B}

Elements shared by both A and B.
Difference: A \ B

{x | x ∈ A ∧ x ∉ B}

Elements in A that are NOT in B.
Complement: Ac

{x ∈ U | x ∉ A}

All elements in Universe U outside A.
